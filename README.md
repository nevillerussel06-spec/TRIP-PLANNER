Trip Planner

**Trip Planner** is a web-based travel management application developed using Python, Streamlit, and SQLite. 
It helps users plan, organize, and manage their trips efficiently through a simple and interactive interface.

Features

- **Trip Management:** Create, view, edit, and delete trips with destination details, travel dates, and budgets.
- **Itinerary Planning:** Organize daily travel activities and places to visit.
- **Expense Tracking:** Record, manage, and monitor trip expenses.
- **Expense Visualization:** View spending patterns through interactive charts.
- **Interactive Maps:** Explore destinations using interactive maps.
- **Distance Calculation:** Calculate driving distance and estimated travel time between your current location and the selected destination.

Technologies Used

- Python
- Streamlit
- SQLite
- Pandas
- Plotly
- Folium
- Geopy
- OSRM Routing API

Key Benefits

- Keeps all travel information organized in one place.
- Helps users plan trips within their budget.
- Makes it easier to manage travel schedules and activities.
- Provides a clear overview of travel expenses.
- Helps users understand routes, driving distances, and estimated travel times.

Project Objective

The main objective of this project is to provide a centralized platform for managing travel plans, organizing itineraries, tracking expenses, 
and exploring destinations, making trip planning easier, smarter, and more convenient.
